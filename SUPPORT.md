# Support

This is a community-maintained fork without a paid support commitment.

Use [GitHub Issues](https://github.com/hshokrig/opencode-bedrock/issues) for reproducible problems with the Bedrock wrapper, SageMaker packaging, offline installer, workspace isolation, or fork-specific native session code. Search existing issues first.

Include the following information after removing all sensitive values:

- the source commit or artifact version
- Linux distribution and CPU architecture
- Python, Bun, Git, and bubblewrap versions
- SageMaker application type, if applicable
- whether the failure is in build, install, `doctor`, start, task, approval, attach, chat, or AWS verification
- the command that failed and the smallest useful error excerpt
- whether the same behavior occurs in unmodified OpenCode

Do not post AWS account IDs, caller ARNs, role ARNs, inference-profile ARNs, bucket names, endpoints containing private names, credentials, session tokens, service passwords, or repository secrets.

Use the private process in [SECURITY.md](SECURITY.md) for suspected vulnerabilities. General OpenCode bugs belong in the [upstream issue tracker](https://github.com/anomalyco/opencode/issues).
